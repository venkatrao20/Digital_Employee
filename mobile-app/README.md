# BA Field Notes

An Expo mobile prototype for capturing customer requirements and reviewing a structured business analysis.

## Run it

1. Install Node.js LTS, then open a terminal in this folder.
2. Run `npm install`.
3. Run `npx expo start`.
4. Scan the QR code with Expo Go, or press `a` for Android / `i` for iOS.

The current analysis action uses a local prototype result so the interface can be exercised before the Python workflow is exposed as an API. The existing Python agents remain unchanged.
